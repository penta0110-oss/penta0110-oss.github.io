# 예온이의 구구단 모험 V5

세로형 모바일 PWA. 기존 `yeon_magicland_v1` localStorage 학습 기록 유지.

- 판다 성장 단계별 이미지 4종 및 움직이는 GIF 4종
- 먹이 주기 흔들림, 성장 확대 효과, 축하 효과음
- 상점 구매/착용 아이템은 예온이 미리보기 옆 아이콘 장식으로 표시 (실제 의상 합성은 미지원)
- 60초 챌린지는 처음부터 실행 가능
- GitHub Pages 저장소 루트에 압축을 푼 파일/폴더를 모두 업로드
- 캐시 갱신 후 새로고침; 휴대폰 브라우저에서 홈 화면 추가
- 기존 버전의 학습·상점·부모님 화면 기능 유지

주의: GIF는 고정된 판다 그림의 부드러운 상하 움직임이며, 관절을 따로 움직이는 프레임 애니메이션은 아닙니다. 실제 휴대폰에서 테스트가 필요합니다.
