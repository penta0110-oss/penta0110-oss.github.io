# 예온이의 구구단 모험 V4

기존 V3를 기반으로 제작했습니다. 2~9단 각 마을의 누적 정답이 최초 15개에 도달했을 때만 마을별 축하 화면이 나타납니다. 일반 정답은 간단한 별빛 메시지로 표시됩니다. 각 축하 화면은 동일한 예온이와 뭉치 이미지 기반이며 마을별 색조·친구·마법 효과가 달라집니다.

## GitHub Pages 업로드
기존 저장소의 `Add file > Upload files`에서 이 폴더의 모든 파일 및 `assets` 폴더를 올리고 커밋합니다. `index.html`, `sw.js` 등 동명 파일을 갱신해야 합니다. 배포 후 이전 캐시가 남아 있으면 앱을 완전히 종료 후 다시 실행하세요.

## 주의
이 파일은 GitHub Pages에서 동작하는 정적 PWA입니다. 저장 데이터는 기존 `yeon_magicland_v1` localStorage 키를 사용하므로 같은 기기·브라우저에서 유지됩니다. 아이의 이미지가 공개 저장소에 노출될 수 있습니다.
